# AndroidのiOSテーマ統合（2026-09-19）

## 現在地
保全 → 環境準備 → Proto公開 → **アプリ改修・確認（現在）** → 最終移行 → 旧サーバー解約。
本変更はAndroidアプリのみ。サーバー、既存回答、通知配信設定は変更していない。

## デザインと実装
- iOSと同じブランド色 #FF5857。KIROKUN共通ヘッダー、中央揃えのプロジェクト名、短いメッセージを表示。
- 回答率の円グラフは未回答Surveyがある場合も表示。回答済みは緑、未回答はアイコンと文言で区別。行は交互の背景色。
- 設問ヘッダーにSurvey名・進捗・入力方式。開始画面は公開日・期限の値を揃える。
- 7種類の入力画面を維持し、ボタン・選択コントロールをテーマに統一。確認画面には回答内容を表示し「回答を送信」。通信成功後に閉じ、失敗時は回答を保持する。
- AndroidはMaterial 3のViews部品と標準SplashScreen APIを使用。iOSのガラス効果の独自模倣や、起動を遅らせる固定待機は追加しない。
- Devアイコンは承認済みの黄色いDEVアイコン。それ以外の共有UIはProtoと共通。
- 文字列は日本語・英語のリソースファイルに分離。必須入力の新仕様は追加していない。
- Devは /api/me でFirebase UIDに対応するuserIdを取得して共通Survey画面へ進む。Devで端末通知トークンを登録しない。

## 2つのビルドを選ぶ
Android Studioの Build Variants で app の Active Build Variant を選択してRunする。

| 選択 | 用途 | アイコン | 接続 |
| --- | --- | --- | --- |
| devDebug | 上松さんの開発・エミュレーター確認 | 黄色 DEV | kirokun-dev / SSHトンネル |
| protoDebug | 既存アカウントでProto確認 | 通常のコーラル | proto.kirokun.alchembright.com |

アプリIDが異なるため同時インストールできる。ログイン画面とメニューのプロジェクト選択は、そのビルドに許可された環境だけを表示する。認証情報を維持したままDev/Protoを相互に切り替える機能ではない。
legacyは移行前の保全用途として残している。新しい確認には使用しない。

```bash
./gradlew :app:assembleDevDebug :app:assembleProtoDebug
```

Devは先にMacからSSH転送を開始し、Android端末に逆転送を設定する。SSH接続は起動したままにする。

```bash
ssh -N -L 18082:127.0.0.1:8082 uva.alchembright.com
# 別のターミナルで
adb reverse tcp:18082 tcp:18082
```

DevDebugのlocalhostはこの転送専用。DevReleaseの公開HTTPS接続は今回の確認対象外。ProtoはHTTPSへ直接接続する。

## 検証結果と残る確認
- devDebug/protoDebugのAPK生成成功。
- 両ビルドのAndroid Lint成功（既存警告は残る）。
- Android 17 / API 37エミュレーターで各6件、計12件の計装テスト成功。
- ログイン画面生成、日本語リソース、回答Parcel、回答確認の値変換、未回答がある場合の円グラフ、7種類の設問画面生成を検証。
- テストはローカルの架空Surveyを使用し、サーバーへ回答を送信していない。
- 追記：小型Android 12LでProtoログイン、回答開始、日本語5件法、自由入力とキーボード時の画面を目視確認。入力時のアイコン・ボタン重なりを修正した。その後のロック解除で全7設問と回答確認の目視を実施し、穴埋め・時間入力・該当なし表示も修正した。追加でDev起動画面、130%文字拡大、端末回転時の縦向き維持を確認。Android 6／12L／17で計60件の回帰テストが成功。実ログイン・実送信・Pushの確認は残る。詳細は [小型端末テスト](android-small-screen-test-20260919.md)。
- AndroidでのGoogleログイン→Survey取得→実回答送信、ProtoのPush通知は今回未検証。実環境での接続確認が必要。

今回のAPKはdebug署名による確認用。ストア配布用の署名・公開は行っていない。既存インストールとの署名が異なる場合は上書きできないため、データを消すアンインストールは先に行わないこと。
